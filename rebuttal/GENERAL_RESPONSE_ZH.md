# 致审稿人与领域主席（AC）的总体回应

感谢各位审稿人认真阅读论文并提出细致的建议。我们很感谢您们认可 TabACE **简洁、与骨干无关的设计**（SbVz 和 bPdS）、**上下文敏感性问题的实际意义**（BV6f），以及**评估的广度和消融实验的价值**（BV6f 和 bPdS）。SbVz 也指出，该方法在改善扰动与偏移下鲁棒性的同时，保持了干净数据上的表现。

这些意见促使我们补充对照、扩展泛化测试，并更细致地分析方法的行为。主要更新如下，**新增附录内容以蓝色标注。**

**对照实验与上下文预算**

- **集成基线**（SbVz、BV6f、bPdS）。 我们比较原生集成、随机上下文集成、静态学习权重、DENSE、PHE、RF-PFN 和 OligoICP，覆盖 TabICL／TabPFN 的分类与回归，并明确部署预算和适配设置（**附录 E.1，表 16–19**）。

- **更大上下文**（bPdS）。 两类任务均扩展至 **1,024、4,096 和 8,192 行上下文**，在干净数据、扰动及偏移下比较 Base、Shared 和 Specific（**附录 E.2，表 20–21**）。

- **微调对照**（SbVz）。 我们测试单独的扰动微调以及叠加 Shared/Specific 的表现，并报告预测性能与训练开销，以考察二者的互补性（**附录 E.6，表 28**）。

**跨机制与跨领域的泛化**

- **未知机制**（SbVz、BV6f、bPdS）。 **2×2 Shortcut 消融**分别检验校准覆盖与构造器匹配的作用；此外，我们在没有专门匹配构造器的情况下评估**三种未知扰动与三种未知偏移**（**附录 E.3–E.4，表 22–24**）。

- **自然与医疗偏移**（SbVz、BV6f、bPdS）。 我们在 Folktables 上补充 **DistPFN–TabICL-v2 与 Drift-Resilient TabPFN** 对照、报告重复实验波动，并在 **PhysioNet Sepsis 2019 与 UCI Diabetes 130-US Hospitals** 上评估医疗迁移（**附录 E.5，表 25–27**）。

**方法分析与实现细节**

- **失效情形与改进**（BV6f、bPdS）。 我们测量高置信 Base 错误、极端回归预测及相关分支共同错误的频率与影响，并在保持骨干冻结的情况下评估改进（**附录 E.7，表 29–31**）。

- **部署与消融**（BV6f、bPdS）。 我们说明上下文类别、分支数量、候选选择及策略拟合，并明确各项消融具体移除的加权项（**附录 B.4–B.5 与 D.3**）。

下文逐点回应各位审稿人的意见。我们认为这些修订回应了大部分疑虑，感谢审稿人帮助我们完善论文的建设性建议，并欢迎进一步讨论。我们也希望领域主席（AC）能评估这些补充结果与说明如何回应审稿中的主要疑虑。
