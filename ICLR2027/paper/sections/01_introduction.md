# Introduction

For a frozen TFM, each prediction depends jointly on its query and labeled context. TFMs are pretrained across tasks and predict queries through in-context learning without dataset-specific parameter updates [@muller2023tabpfn; @hollmann2025tabpfn; @qu2025tabicl; @ma2025tabdpt]. They support classification and regression across healthcare, finance, science, and industry. Changing context examples, features, or labels can still alter the output with model and query fixed [@abdullah2026contextsampling]. Robustness therefore depends on query data and context use.

A task admits multiple contexts through compression, retrieval, sample selection, feature or response transformation, and distribution alignment [@feuer2024tunetables; @thomas2024localpfn; @xu2025mixturepfn; @treerath2026tabaicl; @hollmann2025tabpfn; @khalifa2023dense]. These constructions provide complementary evidence under different changes, but no single construction is reliable across all of them. We refer to the frozen predictor's output from the original, unmodified context as *Base*. Directly averaging conflicting alternatives can degrade an accurate Base prediction. A query-level mechanism must therefore determine whether the alternatives provide sufficiently consistent evidence for an update and anchor the output to Base when that evidence is weak.

**TabACE** implements this decision as a query-adaptive context ensemble without additional backbone training. It retains the original context as Base and constructs complementary contexts through sample composition, feature and response views, and distribution alignment. The same frozen predictor evaluates every context through a common output interface. Confidence and cross-context agreement determine the alternative aggregate, while a task-specific gate controls the update magnitude: stronger support gives the aggregate more influence, whereas weak support anchors the prediction to Base. Construction and fusion use no ground-truth target labels. TabACE-shared uses a fixed context bank across predefined changes without receiving their family or strength. Given a change family before inference, TabACE-specific adds corresponding candidates but receives no strength. The interface transfers across TFMs such as TabPFN, TabICL, TabDPT, and LimiX without architectural changes.

We evaluate TabACE on five controlled context perturbations and seven distribution shifts across OpenML tasks, fully synthetic data, and natural shifts. Across four frozen TFMs (LimiX-2M, TabICL-v2, TabPFN-v3, and TabDPT v1.2), TabACE-shared improves every nonzero OpenML perturbation and shift metric over Base while keeping clean scores close. Across 180 aligned synthetic units, it ranks first in mean pairwise stability win rate, reaching 67.0% for classification and 87.6% for regression. TabACE-specific adds further gains with a change-family prior, and the same interface benefits conventional predictors. Thus configurable contexts can improve inference-time robustness without retraining.
