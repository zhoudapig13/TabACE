# Figures

Place final vector figures here as PDF whenever possible. Each figure should be
generated by a script from audited source data and remain legible in grayscale.
Record the source script and CSV in the caption or manuscript artifact manifest.

## Fixed-bank formula diagnostic

- Script: `../scripts/generate_k5_formula_diagnostic_figure.py`
- Frozen inputs: `../../../PaperResults/tabace_k5_equivalent_component_ablation/summary.csv`
  and `paired_tests.csv`
- Figure data: `tabace_k5_formula_diagnostic_data.csv`
- Outputs: `tabace_k5_formula_diagnostic.pdf`, `.svg`, and `.png`
- Display: five classification and four regression component ablations,
  followed by the highlighted Full reference. Fixed Fusion, confidence
  intervals, the auxiliary gated-formula diagnostic, and the inapplicable
  regression confidence placeholder are omitted from the figure.

## Gate-bin analysis

- Script: `../scripts/generate_gate_bin_analysis.py`
- Frozen summary: `../../../PaperResults/tabace_gate_bin_analysis_soft/gate_bin_summary.csv`
- Source metadata: `../../../PaperResults/tabace_gate_bin_analysis_soft/source_metadata.json`
- Outputs: `tabace_gate_bin_analysis.pdf`, `.svg`, and `.png`
- Display: task-wise $U_i/E_i$ tertile heatmaps for mean $\alpha_i$, loss gain
  relative to Base, material-modification rate, and worsening rate among
