## Official Comment C1：超出校准覆盖与构造器匹配范围的泛化

感谢审稿人提出 TabACE 是否依赖评估机制匹配的问题。我们分别检验了**校准覆盖和构造器匹配**，并进一步评估既未参与校准、也没有专门匹配构造器的新机制。

## Official Comment C4：高置信错误与回归鲁棒性

感谢审稿人指出这些失效情形。我们在重建基准上量化了其频率及影响，并在保持骨干冻结的前提下评估了改进方案。

**高置信 Base 错误仅占五扰动评估中全部查询—条件对的 2.06%–2.44%**（附录 E.7.1，表 29，第 43 页）。高置信指 Base 最大类别概率 ≥0.9。我们在更新强度估计中加入 Base／上下文相对置信度、预测分歧与分支共识，使充分的替代证据能够修正高置信 Base 预测。聚合方式不变，新增评分仅在训练折上校准。

| 骨干 | 高置信 Base 错误／全部查询 | 错误修正率：原版 → 扩展 | 修正错误数 | 整体 Acc：原版 → 扩展 |
|---|---:|---:|---:|---:|
| TabICL | 2.06% | 0 → **17.09%** | 648 | 67.5532% → **67.8380%** |
| TabPFN | 2.44% | 0 → **26.43%** | 1191 | 66.1437% → **66.6759%** |

修正率以高置信 Base 错误为分母；Acc 对数据集与评估条件宏平均。**这一扩展修正了其中相当一部分错误，整体净提升较小，分别为 0.285 和 0.532 个百分点。**

**单个极端回归分支在常规评估中的影响较小。**在四组骨干／评估方向设置中，**0.109%–0.379%** 的查询恰有一个替代预测超出下述区间；各组限幅前后平均 $R^2$ 的变化均 **<0.0007**。原方法不额外裁剪标量分支预测，输出为 Base 与替代聚合预测的凸组合。我们在重新融合前加入无需目标标签的中位数中心限幅：

$$
\widetilde y_i^{(r)}=m_i+\operatorname{clip}\!\left(\widehat y_i^{(r)}-m_i,-3s_{\mathrm{src}},3s_{\mathrm{src}}\right),
$$

其中 $m_i$ 为替代预测中位数，$s_{\mathrm{src}}$ 为源标签标准差；Base 不变。在将一个分支替换为极端预测的 TabICL 五扰动压力测试中，限幅将输出位移的第 95 百分位从 **24.264 降至 0.996 个源标签标准差**，**抑制了极端分支的影响，同时保持常规表现。**

回归更新为 $\alpha_i=\alpha_{\max}U_{\mathrm{reg},i}E_i$：分歧影响 $U_{\mathrm{reg},i}$，上下文证据也共同控制更新。

**共同错误且产生实质性融合损害的情况仅占查询—条件对的 0.021%–0.547%**（附录 E.7.2，表 30–31，第 43–44 页）。严重共同错误指五个替代分支均同向出错，且各自误差 >3 个评估目标标准差；实质性损害指融合平方损失比 Base 高出 >0.01 倍目标方差。发生率以全部非零强度查询—条件对为分母，评估标签仅用于这些事后诊断。

| 骨干 | 评估方向 | 严重共同错误 | 严重共同错误且产生实质性融合损害 |
|---|---|---:|---:|
| TabICL | 五扰动 | 3.147% | 0.219% |
| TabICL | 七偏移 | 0.081% | 0.025% |
| TabPFN | 五扰动 | 4.017% | 0.547% |
| TabPFN | 七偏移 | 0.084% | 0.021% |

我们结合源数据校准的残差修正与学习到的损害风险评分，将高风险更新向 Base 收缩，并以源域尺度约束最终更新。下列重建结果先在各评估方向内宏平均，再对扰动与偏移等权汇总。

| 骨干 | Clean $R^2$：原版 → 扩展 | 扰动／偏移 $R^2$：原版 → 扩展 | 扰动／偏移 nRMSE：原版 → 扩展 | 严重共同错误子集中的额外融合损害回收率 |
|---|---:|---:|---:|---:|
| TabICL | 0.71918 → **0.72052** | −0.12264 → **−0.09363** | 0.89654 → **0.88471** | **30.32%** |
| TabPFN | 0.72387 → **0.72542** | −0.19912 → **−0.16110** | 0.91558 → **0.90061** | **64.75%** |

额外融合损害为 $\max\{\ell(\widehat y_{\mathrm{TabACE}},y)-\ell(\widehat y_{\mathrm{Base}},y),0\}$；回收率以固定严重共同错误子集中原有的该项损害总量为分母。**这一扩展小幅改善了平均表现，并回收了该低频子集中较大比例的融合损害。** 感谢您的建议，促成了这些改进。

## 第 4 部分：Folktables 配置、随机种子波动与偏移方法对照

> 在 Folktables 评估中，Specific 指定了哪个家族？作者能否报告不同随机种子下的方差，并与 DistPFN 和 Drift-Resilient TabPFN 比较？

**上下文构造（附录 E.5.1，第 40 页）。** 记 $z_i$ 为稳健标准化的源特征，$d_i$ 为到目标批次十近邻的平均平方距离。离群分数与源标签冲突度分别为：

$$
o_i=\frac{1}{p}\sum_{j=1}^{p}z_{ij}^{2},\qquad
\delta_i=1-\max_c\frac{1}{10}\sum_{k\in N_{10}(i)}\mathbf{1}[y_k=c].
$$

其中 $p$ 为特征数，$N_{10}(i)$ 为源域十近邻。除特别说明外，保留分数最低的源样本，再无放回抽样。

- **目标邻域（Shared／Specific）：** 由目标批次各维的 10%、30%、50%、70%、90% 分位点组成锚点集 $A_Q$，按 $s_i=\min_{a\in A_Q}\lVert z_i-a\rVert_2^2$ 排序，保留前 80%。
- **代表性样本（Shared／Specific）：** 按 $s_i=d_i+0.35o_i$ 排序，保留前 70%。
- **局部稳定（Shared／Specific）：** 按 $s_i=\delta_i+0.10d_i$ 排序，保留前 80%。
- **特征子空间（Shared／Specific）：** 从上下文与查询中同步移除 $j^*=\arg\max_j\lvert\operatorname{corr}(X_j,y)\rvert$，再抽取源样本。
- **低冲突（Shared／Specific）：** 按 $s_i=\delta_i+0.20o_i$ 排序，保留前 75%。
- **目标匹配 Bootstrap（Specific）：** 连续特征标准化、类别特征 One-hot 编码后，按 $w_i\propto\exp(-d_i^{\mathrm{mix}}/h)$ 有放回抽样；$d_i^{\mathrm{mix}}$ 为到目标批次十近邻的平均平方距离，$h$ 为正距离中位数，并保留类别覆盖。
- **密度比 Bootstrap（Specific）：** 使用逻辑回归域分类器估计 $g(x)$，按 $w_i\propto[\min\{\frac{g(x_i)}{1-g(x_i)}\frac{n_s}{n_t},10\}]^{1/2}$ 有放回抽样并保留类别覆盖；$n_s,n_t$ 为源域、目标域样本数。
- **连续特征对齐（Specific）：** 对预先指定的连续特征施加 $T(x)=0.5x+0.5[(x-m_s)s_t/s_s+m_t]$，其中 $m$ 为中位数，$s=\max(\mathrm{IQR},1)$。无放回抽取源样本，保留源标签与类别特征。

## 第 5 部分：回归共同错误与分类高置信错误

> 由于 Ureg 随 Base 与聚合预测之间的分歧增大而增大，当替代预测与 Base 分歧最大时，更新幅度也最大。当替代预测相互相关且共同出错时，该方法会如何表现？
> 在分类中，低熵但错误的 Base 预测会关闭门控，可能阻止有用的修正。这种情况发生得多频繁，又如何影响整体性能？

感谢您指出这些局限。**Official Comment C4** 给出完整诊断与扩展结果（附录 E.7，表 29–31，第 43–44 页）。

**回归：**更新 $\alpha_i=\alpha_{\max}U_{\mathrm{reg},i}E_i$ 同时依赖分歧与上下文证据，但相关的替代分支仍可能对错误答案达成一致。严重共同错误且产生实质性融合损害的情况占全部查询—条件对的 **0.021%–0.547%**。源数据校准的残差修正与风险收缩，使 TabICL 扰动／偏移平均 $R^2$ 从 **−0.12264 升至 −0.09363**，TabPFN 从 **−0.19912 升至 −0.16110**，并回收该子集 **30.32%／64.75%** 的额外融合损害。

**分类：**高置信 Base 错误（最大概率 ≥0.9）占查询的 **2.06%–2.44%**。更新强度加入相对置信度、分歧及共识后，修正 **17.09%／26.43%** 的此类错误，整体 Acc 从 67.5532%／66.1437% 升至 **67.8380%／66.6759%**。这些情形测得的总体影响有限，扩展在保持骨干冻结的情况下带来小幅整体改进。
