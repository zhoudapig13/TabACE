## Official Comment C4：高置信错误与回归鲁棒性

感谢审稿人指出这些失效情形。我们在重建基准上量化了其频率及影响，并在保持骨干冻结的前提下评估了改进方案。

**高置信 Base 错误仅占五扰动评估中全部查询—条件对的 2.06%–2.44%**（附录 E.7.1，表 29，第 43 页）。高置信指 Base 最大类别概率 ≥0.9。我们在更新强度估计中加入 Base／上下文相对置信度、预测分歧与分支共识，使充分的替代证据能够修正高置信 Base 预测。聚合方式不变，新增评分仅在训练折上校准。

| 骨干 | 高置信 Base 错误／全部查询 | 错误修正率：原版 → 扩展 | 修正错误数 | 整体 Acc：原版 → 扩展 |
|---|---:|---:|---:|---:|
| TabICL | 2.06% | 0 → **17.09%** | 648 | 67.5532% → **67.8380%** |
| TabPFN | 2.44% | 0 → **26.43%** | 1191 | 66.1437% → **66.6759%** |

修正率以高置信 Base 错误为分母；Acc 对数据集与评估条件宏平均。**这一扩展修正了其中相当一部分错误，整体净提升较小，分别为 0.285 和 0.532 个百分点。**

**单个极端回归分支在常规评估中的影响较小。**在四组骨干／评估方向设置中，**0.109%–0.379%** 的查询恰有一个替代预测超出下述区间；各组限幅前后平均 $R^2$ 的变化均 **<0.0007**。原方法不额外裁剪标量分支预测，输出为 Base 与替代聚合预测的凸组合。我们在重新融合前加入无需目标标签的中位数中心限幅：

$$
\widetilde y_i^{(r)}=m_i+\operatorname{clip}\!\left(\widehat y_i^{(r)}-m_i,-3s_{\mathrm{src}},3s_{\mathrm{src}}\right),
$$

其中 $m_i$ 为替代预测中位数，$s_{\mathrm{src}}$ 为源标签标准差；Base 不变。在将一个分支替换为极端预测的 TabICL 五扰动压力测试中，限幅将输出位移的第 95 百分位从 **24.264 降至 0.996 个源标签标准差**，**抑制了极端分支的影响，同时保持常规表现。**

回归更新为 $\alpha_i=\alpha_{\max}U_{\mathrm{reg},i}E_i$：分歧影响 $U_{\mathrm{reg},i}$，上下文证据也共同控制更新。

**共同错误且产生实质性融合损害的情况仅占查询—条件对的 0.021%–0.547%**（附录 E.7.2，表 30–31，第 43–44 页）。严重共同错误指五个替代分支均同向出错，且各自误差 >3 个评估目标标准差；实质性损害指融合平方损失比 Base 高出 >0.01 倍目标方差。发生率以全部非零强度查询—条件对为分母，评估标签仅用于这些事后诊断。

| 骨干 | 评估方向 | 严重共同错误 | 严重共同错误且产生实质性融合损害 |
|---|---|---:|---:|

我们结合源数据校准的残差修正与学习到的损害风险评分，将高风险更新向 Base 收缩，并以源域尺度约束最终更新。下列重建结果先在各评估方向内宏平均，再对扰动与偏移等权汇总。

| 骨干 | Clean $R^2$：原版 → 扩展 | 扰动／偏移 $R^2$：原版 → 扩展 | 扰动／偏移 nRMSE：原版 → 扩展 | 严重共同错误子集中的额外融合损害回收率 |
|---|---:|---:|---:|---:|
