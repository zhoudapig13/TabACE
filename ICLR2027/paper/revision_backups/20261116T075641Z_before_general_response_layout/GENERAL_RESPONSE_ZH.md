# 致审稿人的总体回应

我们衷心感谢三位审稿人为评估本稿投入的时间与心力。尤其感谢您们认可 TabACE **简洁、与骨干无关的设计**（SbVz 和 bPdS）、**具有实际意义的问题动机**（BV6f），以及**广泛的评估和有信息量的消融实验**（BV6f 和 bPdS）。我们也感谢 SbVz 指出，该方法在改善扰动与偏移下表现的同时保持了干净数据上的性能。

针对这些建设性意见，我们在修订稿中补充了以下实验与说明。**新增附录内容以蓝色标注。**

- **更充分的集成对照。** 我们补充了原生集成、随机上下文集成、静态学习权重，以及 DENSE、PHE、RF-PFN 和 OligoICP 等已有方法，覆盖 TabICL 与 TabPFN 的分类及回归，并明确部署预算和适配设置（**附录 E.1，表 16–19**）。
- **更大的上下文预算。** 我们将 TabICL 的分类与回归评估扩展到 **1,024、4,096 和 8,192 行上下文**，在干净数据、扰动和偏移下比较 Base、Shared 与 Specific（**附录 E.2，表 20–21**）。
- **超出匹配机制的泛化。** 我们补充了区分校准覆盖与构造器匹配的 **2×2 Shortcut 消融**，并在没有专门匹配构造器的情况下评估了**三种未知扰动和三种未知偏移**（**附录 E.3–E.4，表 22–24**）。
- **更多自然偏移证据。** 我们在 Folktables 上增加了 **DistPFN–TabICL-v2 与 Drift-Resilient TabPFN** 对照，报告重复实验的波动，并补充 **PhysioNet Sepsis 2019 与 UCI Diabetes 130-US Hospitals** 的医疗迁移评估（**附录 E.5，表 25–27**）。
- **与扰动微调的对照。** 我们评估了单独微调，以及微调后叠加 Shared/Specific 的表现，并报告预测性能与训练开销，以检验推理时适配在骨干优化之外的价值（**附录 E.6，表 28**）。
- **失效分析与算法改进。** 我们统计高置信 Base 错误、单个极端回归预测及相关分支共同错误，并在保持骨干冻结的情况下评估针对这些情形的扩展（**附录 E.7，表 29–31**）。
- **更明确的部署与消融细节。** 我们扩充上下文类别与分支数量说明，明确候选选择、策略拟合及加权项消融的具体范围（**附录 B.4–B.5 与 D.3**）。

下文逐点说明这些结果如何回应各位审稿人的具体疑虑。再次感谢您们帮助我们完善实验证据并澄清方法，也欢迎进一步提问。
